# AI전략연구소

이선영 소장·신현준 소장의 AI 교육, 실무 저술과 프로젝트를 소개합니다.

- 실무 중심 AI 강의: AI 기본, AI 활용, 업무 특화 강의와 실습.
- 프로젝트: 바이브코딩 취업용 앱을 먼저 소개하고, 반응형 홈페이지와 AI 영상·콘텐츠를 안내합니다.
- 대표 저서: 실제 책 표지와 YES24 도서·작가 페이지 연결.
- 브랜드: 직접 제작한 최종 로고와 SVG·PNG 다운로드.

## 미리보기

Node.js가 설치된 환경에서 npm start를 실행하고 http://127.0.0.1:4173/ 을 엽니다.
별도 설치 의존성은 없습니다. HTML 파일을 직접 열어도 주요 내용을 볼 수 있습니다.

## 교육·협업 문의

분야별 버튼은 안내와 편집 가능한 문의문을 엽니다. 내용을 복사한 뒤 카카오톡 상담 주소에서 직접 전송합니다. 이 사이트에서 발송하거나 서버에 저장하지 않습니다.

## 파일

index.html: 연구소 소개. styles.css: 반응형 레이아웃. app.js: 문의 창·복사 기능과 화면 효과. assets/infographics: 직접 제작한 AI 활용·취업용 앱 인포그래픽. brand.html: 로고 다운로드. assets/books: 저서 표지. server.cjs: 로컬 미리보기 서버.

## 화면 효과

AI 활용 연결선 애니메이션, 마우스에 반응하는 인포그래픽, 스크롤 등장 효과와 읽기 진행 표시를 적용했습니다. 첫 화면의 효과 일시 정지 버튼으로 모두 끌 수 있으며 시스템의 화면 움직임 줄이기 설정도 따릅니다. 모바일 취업용 앱 인포그래픽은 글자 가독성을 위해 세로 구성으로 전환됩니다. 외부 애니메이션 라이브러리나 추적 도구를 사용하지 않습니다.
