# AI전략연구소

이선영 소장·신현준 소장의 AI 교육, 실무 저술과 프로젝트를 소개하는 HTML 홈페이지입니다.

- 실무 중심 AI 강의: AI 기본·AI 활용·업무 특화 강의와 실습.
- 프로젝트: 바이브코딩 취업용 앱, 반응형 홈페이지, AI 영상·교육 콘텐츠.
- 대표 저서: 실제 표지와 도서 링크로 8권 모두 소개. PC 4권씩 2줄, 모바일 2권씩 배치.
- 브랜드: 제공된 최종 로고의 형태·색상·비율을 유지하고 SVG·PNG 다운로드 제공.

## 로컬 미리보기

Node.js 환경에서 `npm start` 실행 후 http://127.0.0.1:4173/ 을 엽니다. 별도 설치 의존성은 없습니다. `index.html`을 직접 열어 주요 내용과 화면 효과를 확인할 수도 있습니다.

## 연구소 전용 인터랙티브 콘텐츠

‘생각이 움직이면, 결과물이 됩니다’는 AI전략연구소 홈페이지를 위해 새로 만든 교육용 예시입니다. 콘텐츠 기획 직무의 아이디어 보드를 소재로 문제 발견 → 기능 설계 → 앱 구현 → 과정 설명을 보여줍니다. 4개 장면을 선택하거나 총 32초로 재생할 수 있습니다. 실제 고객 실적이나 실행 중인 AI 서비스로 제시하지 않습니다.

## 화면 효과

딥 네이비 배경에 블루·시안·보라 빛을 사용합니다. 캔버스 네트워크, 회전 궤도와 부유 오브젝트, 마우스 기울기, 스크롤 등장, 카드·책 표지 반응, 장면 전환, 문의 창 등장과 페이지 진행 표시를 적용했습니다. 첫 화면의 효과 일시 정지 버튼으로 움직임과 콘텐츠 재생을 멈출 수 있습니다. 시스템의 움직임 줄이기 설정에서는 자동 재생 대신 장면별 선택을 제공합니다. 화면 밖과 비활성 탭에서는 반복 움직임과 재생을 멈춥니다.

## 화면 가독성

PC 본문은 16px, 모바일 본문은 15px를 기준으로 조정했습니다. 제목과 설명의 줄바꿈, 버튼 크기, 태블릿 배치를 함께 다듬었습니다. 도서명은 생략하지 않으며, 문의 입력창은 모바일에서 16px로 표시합니다.

## 교육·협업 문의

분야별 버튼을 누르면 안내와 편집 가능한 문의문이 열립니다. 문의문을 복사하고 카카오톡에서 직접 전송합니다. 이 사이트가 문의를 발송하거나 서버에 저장하지 않습니다.

## 구성

`index.html`: 소개와 원본 인터랙티브 콘텐츠. `styles.css`: 반응형 화면·색감·효과. `app.js`: 문의 창·복사·장면 재생·모션 제어. `brand.html`: 원본 로고 다운로드. `assets/books`: 실제 도서 표지와 출처. `assets/infographics`: 취업용 앱 구성도. `server.cjs`: 로컬 미리보기 서버.
