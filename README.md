# AI전략연구소 · 문의 허브
신현준 소장·이선영 소장의 AI 강의, 홈페이지, AI 영상, 바이브코딩 취업용 앱 문의 페이지입니다.

- index.html: 프로필형 문의 페이지.
- brand.html: 직접 제작한 최종 로고와 SVG·PNG 다운로드.
- assets/books: 확인한 실제 저서 표지.
- brand-notes.md: 구성, 사실, 출처 메모.

미리보기: npm start → http://127.0.0.1:4173/
HTML 파일을 직접 열어도 주요 내용을 볼 수 있습니다.

네 가지 문의는 분야별 안내와 편집 가능한 문의문을 엽니다. 내용을 복사한 뒤 기존 카카오톡 상담 주소에서 직접 전송합니다. 이 사이트에서 발송하거나 서버에 저장하지 않습니다.
