# AI전략연구소

이선영 소장·신현준 소장의 AI 교육, 실무 저술과 프로젝트를 소개합니다.

- AI 교육: AI 기본, AI 활용, 업무 특화 강의와 실습.
- 프로젝트: 반응형 홈페이지, AI 영상·콘텐츠, 바이브코딩 취업용 앱.
- 대표 저서: 실제 책 표지와 YES24 도서·작가 페이지 연결.
- 브랜드: 직접 제작한 최종 로고와 SVG·PNG 다운로드.

## 미리보기

Node.js가 설치된 환경에서 npm start를 실행하고 http://127.0.0.1:4173/ 을 엽니다.
별도 설치 의존성은 없습니다. HTML 파일을 직접 열어도 주요 내용을 볼 수 있습니다.

## 교육·협업 문의

분야별 버튼은 안내와 편집 가능한 문의문을 엽니다. 내용을 복사한 뒤 카카오톡 상담 주소에서 직접 전송합니다. 이 사이트에서 발송하거나 서버에 저장하지 않습니다.

## 파일

index.html: 연구소 소개. styles.css: 반응형 레이아웃. app.js: 문의 창과 복사 기능. brand.html: 로고 다운로드. assets/books: 저서 표지. server.cjs: 로컬 미리보기 서버.
